**Asignatura:** Organización Empresarial

**Institución:** Universidad Tecnológica Nacional

## Descripción del proyecto

Este trabajo toma como caso de estudio a TEPEC S.R.L., empresa dedicada a la producción y comercialización de conservas de frutas y hortalizas bajo la marca Río Salado.

Se propone un módulo web para registrar la recepción de materia prima, identificar los lotes mediante códigos QR y facilitar la consulta de su trazabilidad. La información registrada podrá relacionarse con las áreas de producción, calidad y logística.

El proyecto forma parte de un trabajo académico y presenta una propuesta de mejora para la organización.

## Declaración de uso de inteligencia artificial

Se utilizó ChatGPT como apoyo para revisar la coherencia del trabajo y detectar aspectos a mejorar.

Entre los pedidos realizados se solicitó revisar el cumplimiento de las consignas e identificar posibles correcciones en el proceso de trazabilidad, el diccionario de datos y los indicadores. También se emplearon consultas orientadas a la arquitectura del sistema y la teoría general de sistemas, por ejemplo: “Actuá como arquitecto de software y experto en TGS...”.

Las respuestas se tomaron como orientaciones y fueron revisadas por el alumno. A partir de las observaciones recibidas, se corrigió el diagrama BPMN, prestando atención a la representación de los actores externos Cliente y Aduana. También se revisaron los tipos de datos y se descartaron propuestas genéricas que no se ajustaban al caso de la empresa.

La selección y aplicación de las correcciones quedó a cargo del alumno, tomando como referencia el material de la cátedra.
