# Proceso de recepción de materia prima

## Objetivo

Registrar el ingreso de frutas y hortalizas a la planta de TEPEC S.R.L. e identificar cada lote para facilitar su seguimiento.

## Funcionamiento propuesto

1. El personal de recepción ingresa los datos de la materia prima, el productor y la cantidad recibida.
2. El sistema valida los datos y registra el lote.
3. El sistema genera un código QR para identificar el lote.
4. El área de calidad realiza el control y registra el resultado.
5. Si el lote es aprobado, queda disponible para su utilización en producción. Si no es aprobado, se registra la observación y se determina su tratamiento.
